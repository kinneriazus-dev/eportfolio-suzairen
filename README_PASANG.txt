SPPPA 2026 V36 — CLOUDFLARE PAGES PWA

1. Upload ZIP ini atau folder kandungannya ke Cloudflare Pages Direct Upload.
2. Pastikan semua fail/folder berada pada akar laman (index.html, manifest.webmanifest, sw.js, assets/, pdf/, proof/, gallery/, icons/).
3. Buka alamat HTTPS Cloudflare Pages menggunakan Chrome Android. Klik Install App di kanan atas / Chrome > Install app.
4. iPhone: Safari > Share > Add to Home Screen.
5. Musik cuba autoplay; sesetengah pelayar menyekat audio sehingga sentuhan pertama.
6. Aplikasi asas boleh offline selepas pemasangan. Bukti/galeri/PDF dimuat mengikut keperluan dan dicache apabila pertama kali dibuka; ia tidak automatik semuanya offline.
7. JANGAN buka index.html daripada ZIP/file:// untuk ujian pemasangan — PWA memerlukan HTTPS.

Reka bentuk, turutan galeri, dan ayat LOCK dikekalkan daripada V35.
